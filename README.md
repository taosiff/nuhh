# nuhh

An elegant, interactive birthday celebration website created with warm wishes and admiration for Mehjabin Nuha.

## Features
- **Canvas Fireworks Intro:** Dynamic illuminated letter reveal with elegant typography and starlight glow ("HAPPY BIRTHDAY PRETTY" & "MEHJABIN NUHA").
- **Photo Showcases:** Clean, frameless editorial portraits with floating gentle accents.
- **Virtual 3D Cake Ceremony:** Interactive candles that can be blown out with a wish and celebration confetti.
- **Living Meadow Garden:** Procedural blooming meadow with roses, tulips, daisies, sunflowers, and chimes.
- **Interactive Memory Gallery:** 6-photo editorial showcase with customized captions matching every picture.
- **Celestial Constellation:** Galaxy star-linking interactive experience.
- **Birthday Letter Parchment:** 3D wax seal opening into a custom heartfelt birthday letter.

## Running Locally
```bash
node server.local.js
```
Open `http://localhost:3000` in your browser.
